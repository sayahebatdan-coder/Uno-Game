UNO Flip

Kartu tambah +1 sampai +5 di sisi terang, +6 sampai +10 di sisi gelap, dan bisa ditumpuk. Kartu kembar (angka atau jenis sama, warna bebas) boleh dimainkan dua kali dalam satu giliran. Mode turnamen: permainan lanjut sampai semua pemain berperingkat, termasuk saat kamu sudah selesai dan tinggal menonton bot. Lawanmu adalah bot lokal.

Halaman online tidak bisa memanggil API Gemini. Untuk lawan bot Gemini dengan API key, unduh file HTML-nya dan buka di browser.
